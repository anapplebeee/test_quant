# Quart 量化平台能力缺口与交付路线

> 文档日期：2026-09-01  
> 文档性质：路线图实施审计、能力缺口校准和后续需求基线  
> 适用范围：A 股日频研究、组合构建、回测、Paper 交易和后续小资金实盘准备  
> 上位约束：`QUANT_PLATFORM_REFACTOR_ROADMAP.md`、`docs/TARGET_ARCHITECTURE_V3.md`、已接受 ADR  
> 开发流程：`docs/DEVELOPMENT_COORDINATION.md`

## 1. 文档目标

本文解决三个问题：

1. 核验 `QUANT_PLATFORM_REFACTOR_ROADMAP.md` 的改造是否真正进入主链路；
2. 校准“策略覆盖、因子数据和 AI/ML 能力”与当前代码现状之间的偏差；
3. 将剩余工作拆成可开发、可测试、可验收的工作包，作为后续排期和状态更新依据。

本文不承诺收益，不以单次回测 CAGR 作为完成标准。所有策略和因子必须经过
PIT、连续样本外、成本、容量和风险门禁后，才允许申请进入 Paper 或 live
白名单。

## 2. 审计口径

### 2.1 状态定义

| 状态 | 定义 |
|---|---|
| ✅ 已落地 | 领域实现、主链路接线、可重复测试和文档均已完成，满足路线图交付条件 |
| 🟡 部分落地 | 已有模块、研究原型或局部测试，但数据覆盖、主链路接线或验收条件仍不完整 |
| ⬜ 未落地 | 缺少正式模块，或只有概念/脚本，无法构成平台能力 |

“文件存在”“测试中能独立实例化”或“研究脚本跑出结果”均不等于正式落地。
必须反向检查实际的回测、信号、Paper 和前端入口是否调用该能力。

### 2.2 审计结论

按主路线图第 15 节 36 个里程碑事项严格判定：

| 里程碑 | 已落地 | 部分落地 | 未落地 | 总体判断 |
|---|---:|---:|---:|---|
| M1 研究可信度基线 | 1 | 4 | 1 | 研究框架可用，完整 PIT、质量门禁和容量场景不足 |
| M2 规则和组合风险 | 1 | 4 | 1 | 状态机和 Kill Switch 已有，规则与组合风险仍未统一 |
| M3 组合构建和策略升级 | 0 | 1 | 5 | 当前最大的架构缺口 |
| M4 模拟交易闭环 | 8 | 4 | 0 | 完成度最高，仍需自动账本、对账和执行归因 |
| M5 小资金实盘准备 | 0 | 3 | 3 | 尚未达到 live 准入条件 |
| **合计** | **10** | **16** | **10** | **没有全部落地** |

现有自动化切片已通过 220 项定向测试。该结果证明已实现部分稳定，但不改变
缺失能力的状态。

## 4. 市场策略与方法论差距校准

### 4.1 策略覆盖

| 策略大类 | 当前状态 | 校准后的判断 | 近期优先级 |
|---|---|---|---|
| 多因子指数增强 | 🟡 部分 | 有因子、基准诊断和低波行业内标准化，但没有相对基准约束优化器 | P0 |
| 全市场量化选股 | 🟡 部分 | 动态因子参数已经可进入回测，但仍依赖策略内部合成 | P0 |
| 小市值/中证2000增强 | 🟡 研究因子 | 有 `size_neg/size_weight`，无市值分层和暴露控制 | P1 |
| 质量价值 | 🟡 数据/因子 | 有财报 PIT 和候选因子，无独立策略准入 | P1 |
| 风格/行业轮动 | 🟡 研究拒绝 | 行业切换原型在预指定 OOS 上失败，不能视为已覆盖 | P1 研究 |
| 市场中性 | ⬜ | 缺股指期货数据、保证金、展期、基差和对冲优化 | P2 |
| CTA | ⬜ | 缺期货资产抽象、连续合约和期货账本 | P2 |
| 套利 | ⬜ | 缺多腿订单、实时数据、基差和原子执行 | P3 |
| 高频/日内 | ⬜ 且暂不建设 | 当前为 A 股日频 T+1 平台，投入产出和合规成本不匹配 | 非近期范围 |

### 4.2 因子与数据能力

当前因子注册表已有 35 个因子规格，不再是“33 个且 100% 量价”。已覆盖：

- 量价、波动、尾部风险、动量、反转、流动性和行业相对因子；
- 市值、EP/BP、ROE 稳定性、盈利加速度和业绩超预期代理；
- 涨停/追板拥挤、容量化拥挤、板块拥挤；
- 龙虎榜、公告事件和市场广度研究合同。

但必须区分“已有因子代码”和“已准入生产”：

- RESEARCH-002 事件/财报组合未通过 1x/2x 成本和超额门禁；
- 行业轮动预指定 OOS 失败；
- LambdaRank 原型 CV 与诊断 RankIC 均为负；
- 市场状态路由只证明条件 IC 存在差异，尚未形成可准入组合。

因此后续重点不是继续堆因子数量，而是完成数据覆盖、持有期匹配、组合约束和
独立新样本验证。

### 4.3 外部规模口径

公开官方数据可确认 2025 年私募证券投资基金总规模已超过 7 万亿元，但没有
给出指数增强、市场中性、量化选股和 CTA 的权威统一拆分。因此外部表格中的
`1.19/0.74/0.54/0.37 万亿` 只能标记为第三方估算，不作为工程验收标准。

相关监管边界：

- 上交所程序化交易实施细则说明：高频交易按申报/撤单速率或总量识别并接受
  差异化管理；
- 深交所程序化交易管理实施细则已于 2025-07-07 施行；
- 中金所当前提供 IF、IH、IC、IM 股指期货，可作为市场中性后续资产边界。

## 5. 目标能力链

平台下一阶段必须形成以下单一主链路：

```text
不可变 PIT 数据快照
  → 数据质量强制门禁
  → Feature / Factor / Model Score
  → Portfolio Constructor
  → 组合风险与硬约束
  → OrderIntent
  → RuleBook + Pre-trade Risk
  → OMS / Broker Adapter
  → Fill / T+1 Ledger / Reconciliation
  → 归因、漂移和告警
```

禁止出现以下旁路：

- 策略绕过 Portfolio Constructor 直接形成不可审计最终权重；
- 回测使用静态涨跌停规则而 Paper 使用 RuleBook；
- 前端直接读取数据库或报告文件形成第二状态源；
- 研究脚本自动修改 live allowlist；
- 券商超时后未经查询直接重发订单；
- 数据质量失败只告警、不阻断正式运行。

## 6. 分阶段交付路线

### 阶段 0：状态真值收敛，2～3 个工作日

目标：消除主路线图、协调文档和代码状态之间的漂移。

交付：

- 建立“路线图事项→代码入口→测试→Artifact→状态”的追踪矩阵；
- 将严格完成、部分完成和研究原型分开记录；
- 为每个未完成项创建唯一工作包 ID；
- 只有 Exit Gate 通过后才允许更新主路线图勾选。

### 阶段 A：可信度与统一规则闭环，P0，2～3 周

包含 `DATA-002`、`QUALITY-002`、`RULE-002`、`RISK-002`、`EXEC-002` 和
`RESEARCH-BASELINE-002`。

阶段出口：

- 正式运行的数据质量失败会被强制阻断；
- 回测、信号和 Paper 对同一订单解析出同一交易规则；
- 单日损失触发风险状态迁移；
- 成交数量受 ADV 限制并支持部分成交和剩余意图；
- 旧收益结论已经新口径重跑或明确废止。

### 阶段 B：独立组合构建与指数增强，P0/P1，3～5 周

包含 `PORTFOLIO-001` 和 `INDEX-001`。

第一版支持：

- Alpha/排名分数输入；
- 当前持仓、现金、不可交易持仓输入；
- 单票、行业、市值、风格、换手、现金和 ADV 约束；
- Alpha、组合方差和换手成本联合目标；
- 约束使用量、预期风险、预期换手和不可行原因输出；
- 沪深300、中证500、中证1000、中证2000模板；
- 因子研究页生成组合回测配置，而不是直接改 live 参数。

阶段出口：策略输出与最终权重分离，同一 Alpha 输入可以被不同基准和风险预算
构造成不同组合。

### 阶段 C：基本面、资金面和事件数据扩展，P1，4～8 周

包含 `FACTOR-DATA-002` 和 `RESEARCH-004`，可与阶段 B 后半段并行。

重点方向：

- 盈利质量、现金流质量、应计异象、资产增长；
- 股息率、EP/BP、GARP；
- 融资融券、互联互通资金和可获得的机构资金流；
- 龙虎榜席位、打板失败、炸板率、封单和公告事件；
- 市值分层和中证2000专项审计；
- 事件因子独立短周期组合，禁止直接混入 20～45 日低换手组合。

阶段出口：每个候选具有披露/到达/修订时间、独立 OOS、FDR、成本、容量和
市场状态分段证据。

### 阶段 D：模型治理与 ML 升级，P1，3～6 周

包含 `MODEL-001`。

顺序：

```text
线性合成长期基线
→ LightGBM 回归管线 sanity check
→ LambdaRank 新样本复验
→ GRU/Transformer 增量价值验证
```

先完成模型、特征、标签、训练数据、代码、预测和保鲜期注册，再讨论复杂模型。
LLM 只允许在研究沙箱中生成假设、表达式和测试，不得自动提升候选或修改
生产配置。

### 阶段 E：多策略与衍生品，P2

顺序：

1. 多因子指数增强；
2. 小市值/中证2000增强；
3. 质量价值；
4. 新样本通过的行业/风格轮动；
5. 市场中性；
6. CTA；
7. 期现、跨市场和期权套利。

市场中性开始前必须完成期货行情、合约主数据、连续合约、保证金、展期、基差、
期货费用和账户账本。CTA 复用同一资产抽象和期货执行底座，不单独建立旁路。

### 阶段 F：生产与实盘准入，连续 2～3 个月 Paper

包含 `PROD-002` 和 `BROKER-002`。

顺序：

```text
Paper 连续运行
→ 券商查询与对账
→ 资产和成交同步
→ 撤单
→ 单账户小资金报单
→ 逐笔复盘后分阶段扩容
```

任何历史回测结果都不能直接跳过 Paper 进入自动实盘。

## 8. P0 工作包需求定义

### 8.1 DATA-002：完整 SecurityMaster 与公司行为账本

**目标**：让任意历史日期的可投资状态、交易规则输入和复权处理均可审计。

**非目标**：不在本工作包中引入分钟/Tick 数据或衍生品。

**数据/schema 变化**：

- 补齐上市、退市、风险警示、停复牌、退市整理和简称生效区间；
- 新增公司行为事件、原始价格、复权因子和版本；
- 明确公告时间、供应商到达时间和修订时间；
- 数据快照写入真实 `security_master_version` 和 `corporate_action_version`。

**验收标准**：

- 随机抽取历史日期可以导出证券状态证据；
- 除权、送转、分红、退市和停复牌样例收益与人工核算一致；
- 未知上市日或状态覆盖不足时 formal 运行失败；
- 数据修订会改变快照和 Artifact 指纹。

**测试计划**：历史区间单测、公司行为账本守恒、复权前后收益不变量、退市和
ST PIT 集成测试。

### 8.2 QUALITY-002：数据质量强制门禁

**目标**：把现有扫描器升级为因子、回测和信号的必选 Preflight。

**检查项**：新鲜度、重复/缺失日期、OHLC、价格/量/额异常、复权跳变、多源
一致性、股票池/基准/PIT 覆盖率、公司行为版本和财报披露覆盖。

**验收标准**：

- `formal` 和每日信号不能通过 CLI 或前端绕过；
- 每条失败包含数据集、日期、标的、规则 ID、阈值和修复建议；
- 探索模式可以继续，但 Artifact 必须标记 `NON_FORMAL/DEGRADED`；
- 前端展示最近门禁状态和阻断原因。

### 8.3 RULE-002：统一 RuleBook

**目标**：回测、计划、Paper 和未来 live 使用同一条规则解析链。

**实现要求**：

- BacktestExecutionModel 注入 RuleBook 和 SecurityMaster；
- 删除或封装静态代码前缀规则，禁止形成第二事实源；
- 按交易日解析涨跌停、无涨跌幅、整手/零股、tick、价格笼子和停牌；
- Artifact 固化实际 rulebook 内容版本。

**验收标准**：同一订单在回测与 Paper 的合法性、涨跌停价格和数量单位完全
一致；历史规则变更前后解析结果不同。

### 8.4 RISK-002：组合级风险和日损状态机

**目标**：形成权重级、订单级和账户级统一硬风控。

**新增输入**：日初权益、当前权益、行业/风格/Beta 暴露、预期波动率、相关簇、
当日换手、预计费用、ADV、不可退出持仓、数据/模型/账户状态。

**状态要求**：

- 单日损失超限：ACTIVE→REDUCING 或 HALTED；
- 数据、账户或对账异常：HALTED；
- 无法退出的持仓保留降风险意图；
- 恢复必须经过 RECOVERY 和人工确认；
- 任一动作记录输入、规则结果、限额版本和输出。

**验收标准**：风控后风险不得高于风控前；HALTED 不产生新增风险订单；
`max_daily_loss_pct` 有真实触发测试，不再只是配置字段。

### 8.5 EXEC-002：容量和部分成交

**目标**：避免日线回测假设大额订单在开盘全部成交。

**第一版模型**：

- 最大成交数量 = min(目标数量、ADV 参与率上限、当日可成交量代理)；
- 超出部分生成剩余意图；
- 支持开盘涨跌停、停牌、开盘/VWAP/收盘三种执行场景；
- 冲击成本基于本笔订单额而非持仓市值；
- 支持账户规模和 ADV 上限二维压力测试；
- Paper 实际成交用于校准滑点和成交率。

**验收标准**：任何成交不突破容量约束；部分成交、未成交和延期均可在结果页
解释；2 倍成本和不利成交场景仍有正期望才可申请准入。

### 8.6 PORTFOLIO-001：独立 Portfolio Constructor

**目标**：把策略评分与最终权重分离。

**统一输入**：Alpha 分数、基准权重、当前持仓、现金、协方差、行业/风格暴露、
流动性、成本、不可交易集合和风险限额。

**统一输出**：目标权重、预期收益/风险/换手/成本、每条约束使用量、调仓原因和
不可行原因。

**第一版目标函数**：

```text
maximize alpha·w
       - risk_aversion·portfolio_variance
       - turnover_penalty·turnover_cost
```

**验收标准**：

- 行业、市值、风格、单票、现金、换手和 ADV 约束均有单测；
- 不可交易持仓被冻结；
- 同一输入确定性输出；
- 无可行解时明确失败，不静默回退为等权 Top-K；
- `factor_portfolio` 和 `index_enhancement` 只能经 Constructor 输出权重。

## 9. 策略和模型准入门禁

### 9.1 Research Gate

- 完整 PIT 数据和内容快照；
- 可交易标签和持有期匹配；
- IC/RankIC、分组收益和经济逻辑；
- 行业、市值、Beta 和流动性归因；
- FDR/多重检验；
- 独立验证段不得回看调参。

### 9.2 Portfolio Gate

- 连续 OOS 超额为正；
- 相对基准约束满足；
- 参数邻域平滑；
- 成本加倍后不结构性失效；
- 容量与账户规模匹配；
- 收益不集中在少数年份、行业或股票。

### 9.3 Paper Gate

- 连续运行至少 2～3 个月；
- 实际成交率和滑点落在压力模型范围；
- 无未解决对账差异；
- 数据、模型、任务和交易告警有效；
- Kill Switch、断线、重启和重复回报演练通过。

### 9.4 Live Gate

- 券商查询、资产、订单、成交和对账先完成；
- 服务端 live 开关、账户白名单、RBAC 和人工确认生效；
- 单账户、小资金、低 ADV 参与率；
- 每笔订单、成交、费用、持仓和现金逐笔核对；
- 任一无法解释偏差立即 HALT 并回退到 Paper/手动模式。

## 10. 第一批建议迭代

第一批只执行 P0 可信度闭环，不同时启动 GRU、CTA 或高频：

```text
Sprint 1
  STATUS-001
  DATA-002 schema/来源/公司行为合同
  QUALITY-002 强制门禁合同与失败测试

Sprint 2
  RULE-002 回测接入 RuleBook
  RISK-002 max_daily_loss_pct 和状态迁移
  EXEC-002 ADV 上限与部分成交

Sprint 3
  PORTFOLIO-001 最小 Constructor
  INDEX-001 沪深300模板
  RESEARCH-BASELINE-002 旧结论重跑与废止
```

Sprint 3 的出口通过后，再并行推进中证500/1000/2000、基本面/资金面扩展和
模型注册。

## 11. 明确暂不优先

在阶段 A/B 完成前暂不优先：

- GRU、Transformer 或端到端大模型选股；
- LLM 自动生成并上线因子；
- 高频/T+0 和 Tick 级基础设施；
- CTA、期权和跨市场套利；
- 为展示效果继续增加前端页面；
- 根据诊断段结果反复调参并继续称为 OOS；
- 直接接入券商报单或扩大资金。
