## 1. 假设卡（预先规定，见 research-protocol §1）

| 要素 | 规定 |
|---|---|
| **稳定 ID** | `director_sale_support_neg`（家庭族 `director_sale_*`） |
| **经济机制** | 董监高/实控人减持计划预披露后进入减持窗口（一般 ≤15 个交易日），内部人有动机在窗口内**维持/拉抬股价**以便更高价减持；一旦窗口结束支撑撤走，前期被支撑的涨幅**回吐** |
| **预期方向** | **负向**：减持窗口内累计相对强度越高（被拉抬越狠）→ 未来收益越差 |
| **输入** | `data/events/news.parquet` 事件帧中 `share_reduction`（减持）+ 标题筛内部人 + 量价收益 |
| **拉升度量** | 窗口内个股收益 − 当日横截面均值（等权市场）的**逐日累计**（T 日信号仅用 ≤T 数据） |
| **执行时点** | T 收盘信号，T+1 开盘执行（5 日持有） |
| **universe** | 全市场过滤后（剔除科创/创业/ST/次新），事件活跃子集 |
| **对比基线** | 事件活跃等权 + 全市场等权（协议 §诊断 6） |
| **失败标准** | ICIR<0.4；或事件活跃内高-低拉升价差方向与假设相反 |

## 5. 结论

### 假设 FAIL（"减持支撑撤走后回吐"方向不成立）

窗口内拉升越猛的股票，未来相对市场**反而略好**（高-低 +0.077%），与"支撑后回吐"假设**相反**。两种合理解释，均不构成可交易的 alpha：

1. **拉升反映内生动量**：窗口内走强往往反映减持前股价已强（内部人顺势减持），拉升是动量而非人为支撑；
2. **信号冗余**：拉升因子与已有动量/反转类因子高度相关，无正交增量。

### 事件负向暴露（PROVISIONAL，候选非 alpha）

内部人减持事件后 T+1~10 相对市场 **-0.256%**，且单调加深——是**持续负面暴露**而非短期脉冲。这与 RESEARCH-002 §5.7（公告情绪无独立 alpha）及复盘建议一致：**事件更适合作为风险/降权输入（风控、过滤），而非独立选股 alpha**。

幅度不足以支撑策略：-0.256%/10 日，即使 5 日调仓年化也 < 1%，且覆盖仅 1.28%，无法构成持仓主体。
