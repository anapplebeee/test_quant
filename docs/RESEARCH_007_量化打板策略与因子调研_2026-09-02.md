# RESEARCH-007：量化打板策略与因子调研（可落地性映射）

**状态**：调研报告（部分因子可落地，盘口类 BLOCKED，监管类放弃）
**日期**：2026-09-02
**关联**：`ashare-factor-strategy-mining` 协议；平台日线 T+1 低频框架

---

## 1. 核心结论先行

打板策略的**本质**是"用历史概率替代主观判断"——华安实证首板回调策略样本外年化 20.72%（样本内 15.42%），证明其具备真实预测力而非过拟合。但**三个硬约束**决定其在平台的可落地性：

| 约束 | 影响 | 平台立场 |
|---|---|---|
| **监管**（沪深北程序化细则 2025-07） | 异常撤单/频繁申报/盘口排队是重点打击对象 | **放弃**高频申报类，只做日线可观测信号 |
| **数据**（平台仅日线 BarStore） | 无 1 分钟分时、Level-2、竞价 | **BLOCKED**盘口/分时因子 |
| **容量**（打板容量仅 500-2000 万） | 不适合大资金 | 适合个人资金，与平台现状匹配 |

**平台是日线 T+1 低频框架，这反而是优势**：天然规避打板的高频申报监管风险，也规避了盘口数据缺失。

## 2. 打板因子 → 平台可落地性映射

### 2.1 可落地（日线可构造，平台已有基础设施）

**A. 涨停情绪周期（平台已有 `market_limit_sentiment`）**
- `limit_up_breadth`（涨停广度）✓ 已有
- `limit_up_count`（涨停家数）✓ 已有
- `limit_heat_z`（情绪 z-score）✓ 已有
- **待补**：连板高度（最高连板数）、炸板率（涨停后开板比例）、昨日涨停股今日平均收益（赚钱效应）

**B. 涨停事件因子（平台已有 `limit_event_panels`）**
- `speculative_crowding20_neg`（涨停拥挤反向）✓ 已验证（ICIR 0.63）
- `limit_hit_count20_neg` / `near_limit_count20_neg` ✓ 已验证
- **待补**：首板/连板状态、涨停基因（近半年涨停次数）

**C. 首板回调策略（华安实证，最稳健）**
- 核心逻辑：首板涨停后不追高，等回调买入
- 实证：年化 18.21%，样本外反超，与沪深300相关仅 0.14，容量 500-2000 万
- **关键发现**：买入端（回调上限 +3%）是主要收益来源，卖出端优化空间有限
- 平台可构造：首板识别（当日涨停 + 前日非涨停）→ 回调买入 → 持有

### 2.2 BLOCKED（需分时/盘口数据，平台无）

| 因子 | 所需数据 | 平台状态 |
|---|---|---|
| 竞价确认（9:15-9:25 高开+量） | 分时/竞价 | BLOCKED |
| 封板时间/封单量/封单时长 | Level-2 | BLOCKED |

| 盘中确认（分歧转一致） | 分时 | BLOCKED |
| 大单/主力资金流向 | Level-2 | BLOCKED |

### 2.3 监管禁区（主动放弃，与合规冲突）

- 异常撤单、频繁申报、盘口排队
- 高频委托/撤单（沪深北程序化细则重点监控）
- **平台日线框架天然不触碰这些**，无需额外设计

## 3. 与平台已验证因子的关系

打板情绪因子与平台已验证的**涨停拥挤反向**（`speculative_crowding20_neg`，ICIR 0.63）高度相关——都基于涨停/接近涨停行为。需注意：
- 打板是"**追**涨停"，而平台已验证因子是"**反向回避**涨停拥挤"——**方向相反**！
- 平台已验证的 `crowding_liq20_neg`（容量化拥挤）本质是"回避追板拥挤"，而打板策略是"买入即将涨停/刚涨停股"——**两个方向互相矛盾**
- **结论**：打板因子与平台已验证量价复合（拥挤反向）**正交性差且方向冲突**，需独立验证或明确资金分隔

## 4. 建议的可落地打板因子（按优先级）

### P1：涨停情绪周期扩展（日线，平台基础现成）
实现 `limit_up_breadth` 之外的情绪周期状态机（连板高度/炸板率/赚钱效应），判断市场情绪处于主升/震荡/退潮，用于**仓位上限控制**（这是打板盈亏的关键，资料§二）：
- 主升期：涨停>80、炸板率<10%、连板>5 → 高仓位
- 退潮期：涨停<30、炸板率>25% → 低仓位/空仓
- 平台已有 `limit_up_breadth`，补连板高度+炸板率即可

### P2：首板回调策略（日线可落地，实证最强）
- 华安实证年化 18.21%、样本外 20.72%、与沪深300相关 0.14——**这是资料中唯一经过严格样本外验证的打板策略**
- 平台日线完全可构造：首板识别 → 回调买入（上限+3%）→ 持有
- 容量 500-2000 万，与个人资金匹配

### P3：涨停基因/连板状态（横截面过滤因子）
- 近半年涨停次数（"涨停基因"）作为候选池过滤
- 首板/二板/高位板状态分类

## 5. 诚实的风险声明

- **监管边界**：任何打板策略若涉及盘中高频委托/撤单，都与沪深北程序化细则冲突，平台应只做**日线收盘决策、次日执行**（这正是平台 T+1 框架，合规且规避盘口数据需求）
- **滑点/成本**：资料明示单边滑点 0.05%→0.30% 时，首板回调总收益从 151.6% 骤降至 18.4%——**成本是打板策略最大实操风险**，平台 45 日调仓的成本优势在此失效（打板是高换手）
- **因子衰减快**：打板因子有效性周期极短，需高频重新验证
- **容量小**：500-2000 万，不适合放大

## 6. 决策建议

1. **首板回调**（P2）是唯一值得实现的打板策略——实证强、日线可落地、与平台合规框架一致、容量匹配。但需单独评估其换手成本（高换手会打破平台低频成本优势）
2. **情绪周期状态机**（P1）作为**仓位控制输入**复用，不单独选股
3. **放弃**盘口/分时打板因子（数据缺失）与高频申报（监管冲突）
4. 打板因子与平台已验证的拥挤反向**方向冲突**，需独立资金或明确分隔，不可混入现有复合
