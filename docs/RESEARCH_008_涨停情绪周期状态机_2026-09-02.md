# RESEARCH-008：涨停情绪周期状态机（打板情绪因子，日线可落地）

**状态**：`PROVISIONAL`（时序信号，作为仓位控制输入）
**日期**：2026-09-02
**关联**：RESEARCH-007（打板调研）收敛出的唯一日线可落地成果
**交付**：`market_limit_sentiment` 扩展——4 个新情绪字段 + 情绪周期状态

---

## 1. 背景：从打板调研收敛

RESEARCH-007 调研结论：打板选股/执行（首板回调、连板骑乘、概念热度）依赖分时/竞价/Level-2 数据，平台日线框架**不可落地**（首板回调日线复刻年化 -35%~-50%，毛收益为负）。唯一日线可落地的打板维度是**涨停情绪周期**——打板盈亏的关键在"仓位适配情绪"（资料§二），且平台已有 `limit_up_breadth` 基础。

## 2. 实现的情绪因子（`market_limit_sentiment` 新增 4 字段）

| 字段 | 定义 | 日线可构造性（已验证） |
|---|---|---|
| `limit_up_consec_max` | 全市场当日最高连板数（逐日累计涨停 streak） | ✓ 连板识别可靠（2024Q1 中位 5 板） |
| `limit_up_break_rate` | 昨日涨停股中今日未续板比例（日线"炸板"代理，非 Level-2） | ✓ 79% 中位 80.6% |
| `limit_up_money_effect` | 昨日涨停股今日平均收益（相对市场） | ✓ 均值 +2.065% |
| `sentiment_phase` | 情绪周期状态：主升/震荡/退潮 | ✓ 主升 18%/震荡 70%/退潮 12% |

**情绪周期状态机**（资料三档）：
- 主升：涨停 > 80 家
- 震荡：30-80 家
- 退潮：涨停 < 30 家

## 3. 数据验证（日线可构造性）

- **涨停识别**：2024Q1 每日涨停中位 46 家（符合实际），p25=27/p75=64
- **连板高度**：中位 5 板，最大 13 板（2024.9 牛市），合理
- **炸板率**：79.3%（仅 ~20% 涨停次日续板，符合连板低概率）
- **赚钱效应**：+2.065%（首板股次日平均有溢价，符合打板逻辑）
- **情绪周期分布**：主升 18%/震荡 70%/退潮 12% 天数，合理

## 4. 用途：仓位控制输入（非选股因子）

这些情绪字段是**时序信号**（市场级、非横截面），用于：
- **仓位上限控制**：主升期高仓、震荡期中仓、退潮期低仓/空仓（打板盈亏关键）
- **情绪择时**：与平台已有 `limit_heat_z`（净广度 z-score）互补
- **不用于横截面 RankIC**（是市场常数，复制到每只股票会产生伪 IC——保留一维时序）

## 5. 测试（4 项新增，PIT/数值验证）

`tests/test_event_factors.py`：

- `test_market_sentiment_break_rate`：昨日涨停 2 只中 1 只未续 → 0.5；续板 → 0
- `test_market_sentiment_money_effect_positive`：连板股赚钱效应 +5.25% > 0

全量 803 项通过，无回归。

## 6. 诚实局限（PROVISIONAL）

- **炸板率是日线代理**（"未续板"），非 Level-2 盘中炸板，无法捕捉"涨停后开板又回封"
- **情绪周期是描述性分类**，未验证其对仓位/收益的预测力——需要回测"主升加仓/退潮降仓"是否真改善风险调整后收益
- **不改变 allowlist**（时序信号，非选股因子，协议不变量 8）
- 退市数据缺失（PROVISIONAL）
