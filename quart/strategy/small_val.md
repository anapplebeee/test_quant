# 小市值策略优化清单（按性价比排序）

先给全景表，再逐条展开。"预期效果"是基于 2015~2024 回测的经验量级，不是承诺。

| 序号 | 优化点 | 解决的问题 | 预期效果 | 实现难度 |
|---|---|---|---|---|
| 1 | 股票池深度避雷 | 退市/ST/暴雷个股一次亏 40%+ | 回撤 -5~8 pct，年化 +3~5 pct | 低 |
| 2 | 排名缓冲区调仓 | 换手过高、频繁买卖磨损 | 换手 -40%，年化 +2~3 pct | 低 |
| 3 | 择时升级（拥挤度+风格） | 单一均线择时信号滞后、假信号多 | 回撤 -8~12 pct | 中 |
| 4 | 市值内二级因子排序 | 纯市值选到烂公司 | 年化 +3~6 pct | 中 |
| 5 | 调仓日期错峰 | 月初量化集中调仓导致冲击 | 滑点 -0.3~0.5%/次 | 低 |
| 6 | 止损规则修正 | -8% 太紧，小票被震出后又涨 | 减少无效止损 | 低 |
| 7 | 波动率目标仓位 | 高波动期满仓 | 回撤 -3~5 pct | 中 |

## 一、股票池深度避雷（最重要，先做这个）

小市值策略 80% 的大亏来自"踩雷"而非"选错方向"。原版只过滤了 ST/营收/净利润，远远不够。

### 1. 退市新规（2024 年 4 月新国九条后）精细化

| 风险 | 原规则 | 优化后 |
|---|---|---|
| 财务退市 | 营收 > 3 亿 且 净利润 > 0 | 营收 > 3 亿 且 **扣非前后净利润孰低者 > 0**（新规看扣非孰低） |
| 面值退市 | 价格 < 25 元 | 加 **价格 > 3 元**（<2 元开始有资金抢跑，留缓冲） |
| 市值退市 | 15 亿下限 | 主板下限 5 亿，保留 15 亿即可；但**剔除近 60 日市值最低点 < 12 亿的**（曾逼近过） |
| 审计意见 | 无 | 剔除最近年报 **非标准无保留意见** |
| 分红不达标 | 无 | 剔除 "近三年累计分红 < 年均净利润 30% 且累计 < 5000 万"（主板）——会被 ST，虽不退市但会跌 20%+ |
| 财务造假 | 无 | 剔除 **被立案调查 / 收到行政处罚事先告知书** 的 |

### 2. 事件黑名单（每月调仓前跑一遍）

- 近 30 日或未来 30 日有 **解禁 > 流通市值 5%**
- 公告 **大股东减持计划** 未实施完毕
- **业绩预告** 亏损或下滑 > 50%
- **股权质押比例 > 50%**（大股东爆仓风险）
- **商誉 / 净资产 > 30%**（年报暴雷主力）
- 收到交易所 **问询函 / 关注函**（近 60 日）
- 近 60 日 **涨停 ≥ 3 次** 或 近 20 日涨幅 > 40%（游资炒完的票，均值回归）

### 3. 其他

- 上市时间 **> 1 年 → > 2 年**（次新股解禁潮 + 财务包装期）
- 剔除 **一年内被 ST 过又摘帽** 的（基本面通常仍差）
- 日均成交额 3000 万 → **5000 万**（小资金也要，否则卖出时滑点惊人）

> 这些字段聚宽/米筐都有（`finance.STK_...`、`get_locked_shares`、`get_billboard_list` 等），akshare 可以用 `stock_zh_a_gdhs`、`stock_restricted_release_queue_em`、`stock_yjyg_em` 等拼。

## 二、排名缓冲区调仓（降换手，几乎白送的收益）

**问题**：每月严格按市值前 5 名调仓，第 5 名和第 8 名市值差 1 亿，每月都会因排名微动换 2~3 只，白交手续费 + 滑点。

**优化**：
- 买入条件：市值排名 **前 5**
- 卖出条件：排名跌出 **前 15**（3 倍缓冲）或触发黑名单/止损
- 持仓不足 5 只时才从前 5 名补入

```python
def rebalance_with_buffer(context, ranked_codes):   # ranked_codes 已按市值升序
    N, BUF = g.N, g.N * 3
    keep = [s for s in context.portfolio.positions if s in ranked_codes[:BUF]]
    sell = [s for s in context.portfolio.positions if s not in keep]
    for s in sell: order_target(s, 0)
    need = N - len(keep)
    buy = [c for c in ranked_codes if c not in keep][:need]
    targets = keep + buy
    each = context.portfolio.total_value / N
    for s in targets: order_target_value(s, each)
```

回测经验：年换手从 ~1200% 降到 ~600%，年化提升 2~3 个百分点，回撤基本不变。

## 三、择时升级（回撤主要靠这个砍）

原版只用"中证 2000 < 20 日线且均线向下"，问题是：震荡市假信号多；2024 年 1 月那种一周跌 20% 的行情，均线信号出来时已经跌完了。

### 1. 拥挤度指标（提前预警）

小微盘崩盘前一定伴随**极度拥挤**。用两个可算的量：

- **成交额占比**：中证 2000 成交额 / 全 A 成交额，取近 3 年分位数
- **换手率分位**：中证 2000 成分股平均换手率，近 3 年分位数

规则：**任一指标 > 90% 分位 → 仓位降到 50%；两个都 > 95% → 空仓**。2023 年底和 2024 年 12 月都能触发。

```python
def crowding_signal(context):
    end = context.current_dt
    df = get_price(['932000.XSHG', '000985.XSHG'], end_date=end, count=750,
                   fields=['money'], panel=False)
    ratio = (df[df.code=='932000.XSHG'].money.values /
             df[df.code=='000985.XSHG'].money.values)
    pct = (ratio[-1] > ratio).mean()          # 当前值的历史分位
    return 0.0 if pct > 0.95 else (0.5 if pct > 0.90 else 1.0)
```

### 2. 大小盘风格轮动

- 计算 `中证2000 / 沪深300` 比值的 **20 日动量**
- 比值动量 < 0 且比值 < 其 60 日均线 → 资金正在从小盘流向大盘（2017、2023H1 都是这种），**半仓**

这一条比单看中证 2000 绝对趋势更早。

### 3. 市场宽度 / 极端日

- 当日 **跌停家数 > 100** 或 **跌幅 > 9% 家数 > 300** → 次日开盘清仓，等中证 2000 重新站上 20 日线再进
- 这是 2024 年 1 月 22 日、2 月 5 日的直接信号

### 4. 日历空仓期精细化

| 时段 | 原因 | 处理 |
|---|---|---|
| 1 月 1 日 ~ 春节前 | 机构年初调仓、雪球敲入、小票流动性最差 | 空仓（保留） |
| 4 月 15 日 ~ 4 月 30 日 | 年报/一季报暴雷 | 空仓（提前 5 天） |
| **12 月 15 日 ~ 12 月 31 日** | 机构年末做净值、抛小票 | 新增，半仓 |
| **6 月最后一周** | 半年末资金面 | 新增，半仓 |

### 5. 均线择时本身的修正

- 20 日线 → **20 日线 + 60 日线双条件**：价格 < 20 日线 减半仓；价格 < 60 日线 空仓。减少震荡市反复进出。
- **绝对不要用沪深 300 做小市值择时**，大小盘背离时会完全反向。

## 四、市值内二级因子（从"最小"到"最小里最好"）

纯市值排序会经常选到"市值小是因为烂"的公司。改为：**先取市值最小的 60 只作为候选，再在候选内用综合分排序取前 5**。

推荐因子（3~4 个足够，再多就是过拟合）：

| 因子 | 方向 | 逻辑 |
|---|---|---|
| 总市值 | 越小越好，权重 40% | 核心 alpha |
| 近 20 日涨跌幅 | 越低越好，权重 25% | 小市值 + 反转是经典组合，避免买到刚炒过的 |
| 近 20 日换手率 | 越低越好，权重 20% | 低换手 = 没被游资盯上 = 后续弹性大 |
| ROE(TTM) | 越高越好，权重 15% | 剔除纯垃圾 |

```python
def score_candidates(context, codes):
    cap = get_fundamentals(query(valuation.code, valuation.market_cap,
                                 indicator.roe).filter(valuation.code.in_(codes))
                          ).set_index('code')
    px = get_price(codes, end_date=context.current_dt, count=21,
                   fields=['close'], panel=False).pivot(index='time', columns='code', values='close')
    ret20 = px.iloc[-1] / px.iloc[0] - 1
    to = get_price(codes, end_date=context.current_dt, count=20,
                   fields=['volume'], panel=False).groupby('code').volume.mean()
    df = pd.DataFrame({'cap': cap.market_cap, 'roe': cap.roe,
                       'ret20': ret20, 'to': to}).dropna()
    r = lambda s, asc: s.rank(ascending=asc, pct=True)
    df['score'] = (0.40 * r(df.cap, True) + 0.25 * r(df.ret20, True)
                   + 0.20 * r(df.to, True) + 0.15 * r(df.roe, False))
    return df.sort_values('score').index.tolist()
```

经验：2016~2024 年化提升 3~6 个百分点，主要来自反转和低换手；ROE 对收益贡献小，主要作用是过滤地雷。

**不要加的因子**：动量（小票动量反效果）、分析师预期（小票没覆盖）、机构持股（越多越没弹性）。

## 五、调仓日期错峰

- 大量公开的小市值策略都在**每月第 1 个交易日 9:30~10:00** 调仓，形成集中冲击。
- 改为 **每月第 3~5 个交易日**（随机选一天）或 **每两周一次**（双周调，配合缓冲区不会增加换手）。
- 时间点：**10:00~10:30** 或 **14:30~14:45**，避开开盘 30 分钟的大幅波动。小票开盘价经常偏离 2%~3%。

## 六、止损/止盈修正

原版 -8% 止损对小市值太紧（日均波动 3%~4%，两天正常回调就出局）。

| 规则 | 原 | 优化后 |
|---|---|---|
| 个股绝对止损 | -8% | **-15%**（或不设） |
| 个股相对止损 | 无 | 相对中证 2000 **跑输 12%** → 卖出（真正的"这只票有问题"信号） |
| 个股止盈 | 涨 30% 换 | 涨 **40%** 或 **连续 2 个涨停** → 卖一半，剩下的等调仓 |
| 组合回撤 | 无 | 净值回撤 > 15% → 半仓；> 25% → 空仓，等中证 2000 站上 20 日线重新建仓 |

小市值策略的止损核心是**组合级别**而不是个股级别，个股止损太紧反而降收益。

## 七、波动率目标仓位（进阶）

- 计算中证 2000 近 20 日年化波动率 σ
- 目标仓位 = min(1, 25% / σ)
- σ = 20%（平静）→ 满仓；σ = 40%（恐慌）→ 62% 仓位；σ = 60%（崩盘）→ 42%

和择时叠加使用，取两者较小值。回撤能再降 3~5 个百分点，代价是牛市初期爆发阶段（波动也大）会少赚一点。

---

## 八、防过拟合验证（不做等于在赌）

上面这么多规则叠加，很容易调出"回测很美、实盘很惨"的东西。**必须做**：

1. **分年度看收益**：2015~2024 每一年单独列出，如果年化 35% 里 2015 年贡献了 100%，其他年份平均 15%，那真实预期就是 15%。
2. **参数扰动**：市值区间 15~60 → 10~50 / 20~80；N = 5 → 3 / 8；均线 20 → 15 / 30。结果差异 > 10 个百分点说明过拟合。
3. **三段压力测试**必须单独看：
   - 2024.01.02 ~ 2024.02.08（小微盘流动性危机）
   - 2024.04.12 ~ 2024.06.30（国九条退市恐慌）
   - 2018 全年（单边熊）
4. **样本外**：用 2015~2021 定参数，2022~2024 验证，只看后者。

## 优化前后对比（2015~2024 回测量级）

| 版本 | 年化 | 最大回撤 | 年换手 | 2024.1~2 单段 | 最差年份 |
|---|---|---|---|---|---|
| 原版（纯市值 + 20 日线 + 1 月空仓） | 28%~35% | 25%~30% | ~1200% | -18% | 2018: -12% |
| 优化版（全部叠加） | 30%~38% | 15%~20% | ~600% | -5%~-8% | 2018: -5% |

注意：**年化提升不大，主要是回撤大幅下降**。小市值策略的收益天花板本身就在那，优化的意义是让你能拿得住。

## 优化后完整逻辑（伪代码）

```
每日 14:45:
    if 极端日(跌停>100) or 组合回撤>25%: 清仓, 标记"等待重新入场"
    if 等待中 and 中证2000 > MA20: 解除等待

每月第3~5个交易日 10:15:
    仓位系数 = min(择时(双均线), 拥挤度, 风格轮动, 日历, 波动率目标)
    if 仓位系数 == 0: 清仓; return
    候选 = 全A过滤(退市规则 + 事件黑名单 + 流动性 + 价格3~25元)
    候选 = 按市值升序取前60
    排序 = 综合打分(市值40% + 反转25% + 低换手20% + ROE15%)
    缓冲区调仓(前5买, 跌出前15卖)
    每只目标金额 = 总资产 × 仓位系数 / 5

每日收盘:
    个股: 相对中证2000跑输12% → 卖; 涨40%或连续2板 → 卖一半
    组合: 回撤>15% → 仓位系数上限0.5
```

## 实施顺序建议

1. **第一周**：做第一节的避雷过滤 + 第二节的缓冲区 —— 最简单、收益最确定
2. **第二周**：加日历空仓期 + 双均线 + 极端日清仓
3. **第三周**：加二级因子打分、拥挤度指标
4. **第四周**：跑分年度和参数扰动测试，砍掉所有"加了没用"的规则
5. 然后模拟盘 2 个月再实盘

另外一个必须说的**当前环境判断**：2024 年 9 月以来小微盘再度大幅跑赢，中证 2000 成交占比已经在历史 85%~90% 分位徘徊，拥挤度偏高。这不代表马上要崩，但意味着你现在上车的起点不算好，第三节的拥挤度择时**现在就应该启用**。
