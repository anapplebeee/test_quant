## 一、换手压缩：剩余最大的确定性杠杆

成本敏感性曲线（39.1 / 30.9 / 22.7 / 13.9）意味着 **每单位成本吃掉约 8pp**。这暗示 H5 的年换手仍然很高（我估计 800%~1200%）。把换手砍一半，即使因子收益零变化，在 1x 成本下也能拿回 3~4pp，在更接近实盘的 2x 成本下拿回更多。

可测的具体手段（都是在 H5 上做增量，每个单独跑）：

1. **分数缓冲区（不是排名缓冲区）**
   之前的缓冲区是在 Top5 纯市值排名上测的，无效是因为市值排名每月都大幅重排。H5 是 Top10 + 综合分，动态不同。规则改为：持仓股综合分仍在前 **20~25** 名（Top10 的 2~2.5 倍）则不卖。这个值得重测一次，样本不同了。

2. **部分调仓**
   每月只允许替换持仓中分数最差的 **3 只**（Top10 的 30%），其余强制持有。把月换手上限锁死在 ~60%。代价是持仓平均"新鲜度"下降；小市值+反转因子的半衰期大约 1~2 个月，30% 替换率对应平均持有 3 个月，应在容忍范围内。

3. **交易阈值**
   目标权重与当前权重偏差 < 3% 的不交易（等权 10% 下即 ±0.3pp 内不动），消除因净值变动导致的碎单再平衡。

4. **调仓频率 6 周 / 双月对照**
   直接测 H5 在 6 周和 2 个月调仓下的表现。如果双月只掉 2pp 收益但换手减半，2x 成本下反而更优。

5. **只在日历窗口边界做全换**
   1 月末重入、4 月末重入这两次本来就是全仓建仓，其余月份只做部分调仓（结合第 2 点）。

**评价标准**：报告要同时给 1x 和 2x 成本下的结果。**以 2x 成本下的收益为选型依据**，因为小票真实滑点通常比模型高。

```python
# 部分调仓 + 分数缓冲 的核心逻辑（示意）
def rebalance_partial(holdings, ranked, top_n=10, keep_rank=25, max_replace=3):
    rank = {c: i for i, c in enumerate(ranked)}
    keep = [c for c in holdings if rank.get(c, 10**9) < keep_rank]
    drop_candidates = sorted([c for c in holdings if c not in keep],
                             key=lambda c: rank.get(c, 10**9), reverse=True)
    sells = drop_candidates[:max_replace]
    keep += [c for c in drop_candidates if c not in sells]      # 超出替换上限的暂留
    buys = [c for c in ranked if c not in keep][: top_n - len(keep)]
    return keep + buys, sells
```

## 二、成本模型校准：这决定实盘预期而不是回测排名

平台的"impact 0.10"如果是**固定比例、与订单规模无关**，那么对 3 万元订单是过度惩罚（3000 元买一只日成交 5000 万的票，真实冲击接近零）；如果是按 ADV 占比计算，则需要确认小票的 bid-ask spread 是否已单独计入。两个方向的误差可以差 3~5pp/年。

建议：
- 输出 H5 每笔交易的 `order_value / ADV20` 分布。若中位数 < 0.1%，固定 0.10 的 impact 是过度保守，实际预期应更接近"0.5x~1x 成本"那一档。
- 反过来，确认 spread 成本：小票 tick 0.01 元、股价 5~15 元，单边 spread 0.05%~0.1%，这部分往往被 slippage 0.1% 覆盖，但要确认没有漏。
- 校准后，把"实盘预期"重新标定为对应成本档的回测值，而不是简单用 1x。

## 三、日历规则精修（需要预注册，避免再一次事后拟合）

日历空仓是 H5 里贡献最大的风控项（+8.3pp），也是事后成分最重的一项。精修分两件事：

### 1. 空仓期间的资金去向
现在是空仓持现金。1 月是 A 股风格切换最明显的窗口——机构年初配置、大盘/红利相对小盘系统性占优。可测的替代：
- 1 月持 **红利低波 ETF（512890）**
- 1 月持 **国债 ETF / 货币 ETF**（吃利息，差异约 +0.2%）
- 1 月持 **沪深 300 ETF**

**预注册**：三个选项在跑之前先写下预期排序（我的先验：红利 > 国债 > 现金 > 沪深300），跑完只接受与先验一致或差异 < 1pp 的结论。如果红利显著更好但仅由 2024 年 1 月单点驱动，不采纳。

### 2. 4 月窗口的重入时机与重过滤
当前 4/20 后空仓，5 月初重入。两个改进点：
- **重入时用刚披露的年报做退市新规过滤**：4/30 后 PIT 年报全部可用，此时"营收 < 3 亿且扣非亏损"的名单是确定的。确认当前实现是否用了最新年报而不是上一期累计值。这是纠错不是调参。
- **重入日期对照**：5 月第 1 交易日 vs 5 月第 5 交易日 vs 5/15。年报暴雷的 ST 处理在 4/30 后 1~2 周内集中兑现（一字跌停），晚几天进能避开。只跑这三个点，不做更细搜索。

上一轮我已经提过：日历规则的 +8.3pp 里有多少来自结构、多少来自避开 2024Q1 单一事件，必须拆开。这一项是**降低置信度**的检验，不是优化，但应先于上面两项做。

## 六、组合层放置（解决 -35% 红线的唯一可行路径）

G 组已经说明：小市值内部无法压回撤。那么让它进入实盘的唯一方法是**作为一条腿被外部资产稀释**。这是策略之外的优化，但对"3 万元能不能用"至关重要。

要跑的是组合回测而不是单策略回测：
- H5 × w + 低相关资产 × (1-w)，w 取 30% / 40% / 50%
- 低相关资产候选：国债 ETF（511010/511260）、黄金 ETF（518880）、可转债双低组合（若已实现）、红利 ETF
- 月度再平衡，同样走全成本
- 看组合 MDD 是否落入 -20% 以内、Calmar 是否高于 H5 单独

先验判断：H5 的 MDD -35% 主要集中在 2024Q1~Q2；黄金和长债在那段是正收益。40% H5 + 30% 长债 + 30% 黄金 大概率能把组合 MDD 压到 -15%~-20%，年化留下 12%~15%。**这个数字请跑出来再信。**

另外一点：如果组合层需要减仓，是减 H5 的仓位比例而不是让 H5 内部空仓——G1 的教训是"策略内部压仓再重进"入场位置系统性差，组合层再平衡不存在这个问题，因为它是被动的。

# 最终复核修订（2026-09-04，审阅确认 commit 后两处定性再补 + 遗留项）

## 修订 1：防御腿定性升级——黄金是第二条高波动腿，不是防御资产

B1 的 MDD 由黄金单腿 -30.5%（2026H1，仍在水下）造成，长债 -4.6% 才是稳定项。
"长债 50 + 黄金 50"里黄金是**第二条高波动腿**，只是历史上恰好与小盘负相关。三条后果：

1. **P50 过线的前提是黄金下跌时小盘没同时崩**。2026-01→07 两腿方向相反，P50 的 MDD
   没被刷新；**下一次两腿同跌，-15% 会直接变 -20%+**——不是"可能触及"，是有明确
   触发场景的。
2. **模拟盘恰在黄金回撤未结束时启动**——这是对防御腿的真实压力测试，作为测试目的
   之一，不是坏运气。
3. **防御腿改配（长债 70/黄金 30，或加 511010 短债）= 下一轮第一个预注册项**，本轮不动。

## 修订 2：损耗拆分——4.24pp 是资金规模损耗，不是执行损耗，两个都要扣

| 损耗 | 来源 | 量级 | 谁承担 |
|---|---|---|---|
| **资金规模损耗** | 整手取整权重偏离、5 元最低佣金 | SC 腿 ~4pp → 组合 ~2pp | 已由 1.5 万回测计入 |
| **执行损耗** | 滑点、信号→成交延迟、纪律 | 组合 3~5pp | **回测完全未计，靠模拟盘估** |

**P50 前瞻最终数字**：0.5 × (15% − 4pp) + 0.5 × 5% ≈ **8%**，再扣执行损耗后
**5%~7%/年，3 万本金约 1500~2100 元**（以此为准，替代上一稿 7~9%）。

## 遗留项：3.1 时间外重拟合未执行（下一轮预注册固定第 1 项）

3.1（2019~2022 定参 → 2023~2026 盲测）在计划里排第一，被 3.5 门禁与 3.2 挤掉，
预算用尽时仍未执行。当前所有参数（45/30/25、score_top=60、Top10、日历窗口）都是
全样本内定的，没有一次真正的样本外验证。模拟盘是真实 OOS 但 3 个月太短，说明不了
regime 尺度问题。**下一轮预注册：① 3.1 OOS 重拟合；② 防御腿改配**——模拟盘期间
并行跑，不影响启动；若 3.1 盲测与全样本参数差异大，模拟盘结束时一并复核。

## 这条线的最终定性（一句话）

> 3 万元、P50 组合、前瞻 5%~7%/年、MDD 预期 -15%（两腿同跌可至 -20%）、所有策略
> 内部择时已证伪、参数无 OOS 验证、防御腿的黄金部分本身是高波动资产。它是一个
